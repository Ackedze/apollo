# Document audit stage 1

Scope: native locality; published instance-version freshness; explicit current-page Theme/Corp. These diagnostics have an independent `apollo.document-audit.v1` request/result/focus protocol and do not await Proxy/Ready/contracts. No normative contract status is promoted. The page action remains available while `busy || generationBusy || generationLoading || nativeDiagnosticUi.busy()` closes legacy controls: it dispatches only the document request in that state, preserves the pending contract correlation, and never starts another contract audit. Repeated document launches remain blocked during their own loading.

Main validates a closed request: request ID, current page ID, current selection signature and enumerated user-selected platform (Desktop/MobileWeb/iOS/Android). Product channel/page type are not promoted to native facts. The existing contract request, authoring/contract runtime, source loading, generation and free dialogue remain separate.

The native API ports read definitions, component identities, current-page variable modes/collections and published component definitions. `remote === false` establishes locality; missing/failed main is explicit unknown. Local definition source walks preserve owner and selected occurrence targets, stop at remote instance boundaries and retain missing-source gaps. No catalog absence heuristic or lifecycle policy is used.

Published import identity must have exact key, native remote=true and an ID. Current/update outcomes are exclusive; imports are cached only within one run. Independent instances, SLOT projection, instance sublayers and local source dependencies have explicit scopes. Technical/lifecycle policy, full DS relevance, auto-swap and update actions are outside scope.

Theme walks only the current page and follows native resolved collection IDs. One Theme collection and one Corp mode must be unambiguous; explicit page mode is checked. Missing collection/mode, access errors, ambiguous identities and limits are incomplete/unknown. Desktop/MobileWeb apply; iOS/Android do not. Page theme is independent of selected component eligibility. With empty selection, local/freshness report an empty-selection gap; they do not claim a clean document.

Budgets: visible selection 10000 nodes, local definitions 1000, source walk 10000 visits, page search 10000 nodes, 300 published imports and 300 variable collections per run. Findings are capped at 1800 per checker; per-owner occurrence cap is 1000. Response validation is closed and limited to 4 MiB. Timeout is 15 seconds in main and 20 seconds in UI; stopping wait does not promise cancellation of an already dispatched native API import. All limit/error states are explicit.

The observer uses supported current-page nodechange/currentpagechange APIs. Other-page source definitions and variable resources are NOT claimed continuously observed. Native evidence is re-read after collection and before focus; result focus expires after 60 seconds. A finding resolves only to its main-registered target on the current page. Source-owner metadata may refer to another page; no cross-page focus or page loading is performed. PAGE itself is not placed in selection: theme uses a registered scene anchor.

Native results carry separate per-checker scope, complete/incomplete/not-applicable and gaps. `categoryComplete` is always false. Native freshness-current is not contract PASS or full “Current components”; theme completion is not Corporate counterpart coverage. UI uses confirmed native subset counts, distinct unavailable/partial states and human-readable cards. Legacy contract setup is hidden only while a native category result is displayed; its original DOM/handlers and contract view remain intact.

Testing: synthetic source/unit and actual-built UI→actual-built main→synthetic Figma API integration. No live Figma/native import, normative, source Ready, generation target or release acceptance is inferred from these gates. Final General candidate review and exact application handoff are separate from implementation of the private candidate.


## Live-feedback repair — 2026-10-07

The selected category stays selected when an audit starts, when a contract reply arrives, and when selection/focus/invalidation occurs. Native snapshots remain in the regular Local / Current / Update / Theme categories while stale, while a replacement run is loading, and if that run fails. A correlated valid replacement is the only event that replaces the snapshot. Stale/loading/error snapshots are explicitly labelled; all focus actions are disabled. They do not count as current evidence. Summary links are supplemental navigation, not storage or the sole entry point.

PAGE facts never read SceneNode-only `visible` or `resolvedVariableModes`: native PAGE proxies throw for those properties. Current-page `explicitVariableModes` is read first, so page theme works even if the selected frame/instance/sublayer has no variables or eligible component contract. Scene resolved modes provide additional native collection references.

Distinct native collection IDs are reconciled only when the fetched objects establish one exact remote published key. Page explicit ID and scene alias ID may differ. Corp mode ID must agree across representations, and page explicit aliases must not conflict. Additional unrelated modes may exist in one representation. Different keys, contradictory Corp/actual mode identities, missing collection access and traversal limits remain unknown/incomplete. No parsing of ID suffixes or guessed name aliases is used.

Delayed nodechange notifications are rechecked against the captured native facts before a result is invalidated. Unchanged facts remain actionable; changed/unavailable facts invalidate the registry while retaining a non-actionable UI snapshot. A confirmed focus can update expected selection without discarding the observed area; a forged or late focus request cannot invalidate a newer run.

Regression fixtures use invented IDs/keys and strict PAGE getters. Actual owner metadata and General native receipts remain private. Previous user-live feedback failed; this repair's source/unit/browser gates do not establish successful live Figma acceptance. General independent review and owner retest remain separate.

Responsive repair: at 440/360 px the existing category list is bounded to 28dvh (maximum 192px), with its own scroll; the result pane remains in the viewport with independent scrolling. Compact and report/text views keep their existing single-pane behavior. Browser regression verifies result viewport visibility and hit testing at all three widths.

## AREA-LIFECYCLE-DETACH-02

Original roots are captured before asynchronous reads and remain the evidence and
focus boundary after deselection or cursor changes. PAGE/settings/proven source
changes still invalidate explicitly. Contract RPCs no longer share cursor
cancellation with generation-native RPCs; Generation/native-proposal guards and
source files are retained. A correlated contract cancel acknowledges after its
awaited worker has exited; a terminal/cancel race also acknowledges safely.

Native identity and source dependency reads use a 12-worker pool; recheck uses 16
workers and caches node-ID reads per pass. Read deadlines remain 15s main/20s UI,
with bounded per-read waits and budget reserved for recheck. Late native resolutions
cannot start further work or publish results after guarded cancellation. Independent
checkers stream verified snapshots with running coverage; terminal timeout retains
finished findings and marks unfinished coverage incomplete. UI never claims aggregate
completion or enables another run while the other current branch remains active.

Theme evidence is PAGE explicitVariableModes. Descendant resolved modes discover
native identities; they do not overwrite PAGE mode. Only exact remote published key
reconciles aliases. Relevant aliases are checked; confirmed PAGE Theme avoids a
page-wide scan. Unknown unrelated collections can leave incomplete coverage while
preserving an independently proven Theme mismatch. Proofs use invented IDs/keys.

The native detachedInfo transfer is scoped to library provenance on FRAME/GROUP.
The style transfer proves current unbound SOLID paints, effects and typography;
linked-resource unavailability/mixed values are unknown, never historical detach.
Native negative filters preserve IMAGE/invisible/SECTION and exact technical fill
cases. Existing v3 catalog library and raw typography policy gates are not imported
as new normative authority; their unavailable coverage is explicit. No blanket DS
compliance, recipe execution, token/style rebinding or corrective action is added.

User-live retest NOT_RUN after the previously failed owner example. Native getter
capability and synthetic detection are separate from successful actual detach tests.
