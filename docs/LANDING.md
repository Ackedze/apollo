# Генерация Apollo: прямой CLI

Плагин — чат, история, контекст текущего файла и подтверждение структуры.
Через `src/landing/context-native.js` он читает страницу/выбранную секцию;
`open/assemble/observe` отключены. Сам макет создаёт Codex CLI через Figma MCP,
а пакетные знания предоставляет read-only reader Proxy внутри CLI-сессии.

Сценарий: пользовательский бриф → существенные уточнения → общий план →
создание каркаса через MCP → показ/явное подтверждение структуры → наполнение
и проверка. Параметры layout и компоненты следуют Hub, не настройкам плагина.

Proxy сохраняет CLI sessionId, фактически полученные IDs, checkpoint, источники,
usage и ошибки. UI только опрашивает состояние; запись больше не зависит от
canvas callbacks плагина. Stop прекращает CLI; продолжение сначала перечитывает
фактический макет. Установка/закрытие плагина не удаляют результат и историю.

Старые чаты открываются read-only, экспортируются и удаляются из списка.
Их прежний flow не возобновляется. Новый UI требует `direct-cli-mcp-v1` от Proxy
и совместимый пакет навыка0.6.0. Старый runtime не используется как fallback.

Локальный кандидат плагина0.4.16 не является опубликованным Proxy/data релизом.
Ручную установку и проверку полного лендинга выполняет владелец. Автотесты:
`tests/landing-direct.test.js` и `tests/landing-direct.browser.cjs` (800px).
Остаточный старый код удаляется отдельной задачей
`AP-GENERATION-LEGACY-FLOW-REMOVAL-01` после приёмки нового механизма.
